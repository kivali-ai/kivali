# Role icons

A new agent's avatar shows its role icon everywhere, next to its
initials. Pick the icon whose picture best fits the role you drafted
and pass its name as `propose_hire`'s `icon`. When none fits, use
`user`. A name that is not in this list is refused.

Each line is the name, what the icon shows, then the work it suits.
