# Kivali documentation

Kivali runs a team of AI agents that work for you. Each agent has a role, learns as it works, and remembers what it learned. You hire them, give them work, and decide what moves forward.

New to Kivali? Start with [Getting started](getting-started.md), then read [How Kivali works](how-kivali-works.md).

## Get started

- [Getting started](getting-started.md): install Kivali Desktop, create a team, connect Claude, hire your Chief of Staff.
- [FAQ](faq.md): short answers to the questions people ask first.

- [Memory](memory.md): how agents learn and remember, and how you can see and edit what they know.
- [Assignments](assignments.md): the tracker your team works from: goals, parts, questions and holds.
